# ezsy 이지

AI융합 예술교육가 이지연의 교육 브랜드 홈페이지입니다.

- 홈페이지: https://easyiji.netlify.app
- 자료실: https://easyiji.netlify.app/news.html

## 파일 구성
- `index.html` 첫 화면과 모든 섹션
- `news.html` 이지 자료실 전체 보기
- `style.css` 디자인
- `news.js` 자료실 글 목록 (새 글은 맨 위에 추가)
- `news/` 자료실 전체 글 페이지 (글마다 한 페이지)
- `llms.txt` AI용 사이트 안내문
- `news-ui.js` 자료실 화면 표시
- `img/` 이미지, `files/` 내려받는 자료(PDF)
- `sitemap.xml`, `robots.txt` 검색엔진용
